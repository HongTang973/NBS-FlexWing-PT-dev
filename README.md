# NonlinearShapeFunction

Original Author: Dr Chris Howcroft

This codebase allows the simulation of aeroelastic systems using the Nonlinear Shape Functions methodology developed by Chris Howcroft. 

This codebase is maintained by Chris Howcrowft and incremental updates are provided to the University of Bristol. For more information speak to Professor Mark Lowenberg.

## Running the code
Chris has provided two MATLAB LiveScripts (.mlx) which demonstrate some of the basic functionality of the code. 

Unit tests will be added at a later date.
