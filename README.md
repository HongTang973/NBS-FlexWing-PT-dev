# nonlinear_shape_functions

Low-order beam formulation for simulating structural and aeroelastic problems using slender structures. For more information see [this paper](https://doi.org/10.1016/j.ijnonlinmec.2018.11.007) and additional references from Chris Howcroft and Andrew Eaton.

This codebase is maintained by Chris Howcrowft and incremental updates are provided to the University of Bristol. For more information speak to Professor Mark Lowenberg (m.lowenberg@bristol.ac.uk).

## Running the code
Two MATLAB LiveScripts (.mlx) are provided which demonstrate some of the basic functionality of the code. 

Unit tests will be added at a later date.
